  STEP 7 — MODEL SELECTION (CV-based, training data only)
======================================================================
  SELECTION RULE (defined before any test-set results are examined):
  Primary   criterion = highest mean CV ROC-AUC (5-fold, training only)
  Secondary criterion = highest mean CV F1 (tie-breaker)
  Tertiary  criterion = highest mean CV accuracy (second tie-breaker)

  WHY TEST-SET RESULTS ARE NOT USED FOR SELECTION:
  Using the test set to choose between models is a form of test-set
  contamination. If we evaluate all models on the test set and pick
  the one with the highest test metric, we are effectively optimising
  for the test set — the same error we prevent during hyperparameter
  tuning. The selected model would then appear better on the test set
  than it really is, because we chose it precisely because it scored
  highest on that data. The test set must produce a single, unbiased
  estimate of performance for the pre-selected model only.
